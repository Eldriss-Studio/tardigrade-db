const ZSTD_LEVEL: i32 = 3;
Expand description

zstd compression level used by CompressionCodec::ZstdQ4.

Level 3 is the encode/ratio sweet spot for byte-oriented payloads — level 19 buys ~5% more compression for 10× the encode time, which is not worth the write-path latency on a memory engine. Documented in docs/refs/.
