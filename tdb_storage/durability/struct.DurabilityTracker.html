Expand description

In-process durability tracker — the default Durability implementation backing every embedded engine instance.

One instance per engine. Cloneable references via std::sync::Arc let readers wait without holding the engine lock — the Python binding’s confirmed-read path borrows an Arc<dyn Durability>, drops the engine read lock, then calls Self::wait_durable outside the lock so writers can advance the offset concurrently.
